1. Agent collects: destination, items description, estimated weight (kg) and volume (CBM), shipping mode preference
2. Agent calls get_quote tool to calculate price
3. Customer confirms, then agent collects: shipper name, phone, pickup address, preferred pickup date
4. Agent confirms booking and provides reference number
